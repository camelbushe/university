## Определение предела функции
### По Гейне
Число $b$ называется **пределом функции** $f\left(x\right)$ в точке $x=a$ (или при $x\rightarrow a$), если для любой последовательности аргументов $\left\lbrace x_{n}\right.\rbrace$ сходящейся к $a$ (при условии, что $x_{n}\ne a$), соответствующая последовательность значений функции $\left\lbrace f\left(x_{n}\right)\right\rbrace$  сходится к $b$.

Простыми словами, чтобы получить предел функции мы должны последовательность аргументов, стремящуюся к какому-то числу (при этом ни один аргумент не должен ровняться этому числу) прогнать через функцию. И если полученная последовательность будет иметь какой-то предел, то этот предел и есть предел функции.

Предел функции обозначается в виде $\lim_{x\rightarrow a}f\left(x\right)=b$.

### По Коши
### Определение предела функции по Коши

Число $b$ называется **пределом функции** $f(x)$ в точке $x = a$ (или при $x \to a$), если для любого $\varepsilon>0$ существует такое $\delta > 0$, что для всех $x$, удовлетворяющих условию $0<|x-a|<\delta$ выполняется неравенство $|f(x)-b|<\varepsilon$.
## Односторонние пределы
Левосторонний предел показывает куда стремится функция если ее аргумент всегда меньше какого-то числа $a$. То есть аргументы идут слева на права (от меньших чисел в большему) они стремятся к числу $a$ и левосторонний предел функции показывает куда в таком случае стремятся значения функции.

Правосторонний предел показывает куда будет стремится функция если ее аргументы всегда больше какого-то числа $a$. То есть аргументы справа налево стремятся к числу $a$ и левосторонний предел показывает куда в таком случае стремятся значения функции.
