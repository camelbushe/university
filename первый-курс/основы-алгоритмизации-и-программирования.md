# Введение в алгоритмизацию
## Понятие алгоритма
**Алгоритм** - это точная, конечная последовательность шагов
(инструкций), описывающая процесс решения определённого класса
задач или достижения конкретной цели.

В программировании алгоритмы используются для обработки данных,
выполнения вычислений, автоматизации процессов и многого другого.
## Понятие алгоритмизации
**Алгоритмизация** - процесс разработки алгоритма для решения
какой-либо прикладной задачи. Она включает в себя анализ задачи,
проектирование последовательности шагов (алгоритма), а также проверку
и оптимизацию этого алгоритма.

Алгоритмизация является ключевым этапом при программировании и
разработке программного обеспечения, т.к. прежде чем написать код,
необходимо продумать логику решения задачи в виде алгоритма.
## Основные свойства алгоритма
- ### Конечность
  Алгоритм всегда заканчивается после выполнения
конечного числа шагов. Это значит, что в нем не должно быть
бесконечных циклов.
- ### Дискретность
  Алгоритм разделён на ряд отдельных законченных действий.
- ### Детерминированность (определённость)
  Каждый шаг алгоритма
должен быть строго и однозначно определен. Не должно быть
двусмысленности в том, что делать на каждом этапе.

  Детерминированность гарантирует, что алгоритм при одних и тех же
входных данных всегда дает один и тот же результат.
- ### Понятность
  Алгоритм должен быть описан на доступном для
понимания исполнителя языке. Каждый шаг должен быть простым и
выполнимым.

  Понятность алгоритма позволяет избежать ошибок при
его выполнении.
- ### Массовость
  Алгоритм предназначен для решения не одной
конкретной задачи, а целого класса однотипных задач (например,
алгоритм сложения работает для ЛЮБОЙ пары чисел).
- ### Результативность
  Выполнение алгоритма должно приводить к
конкретному результату (решению задачи) или обоснованному
выводу о его отсутствии.
## Понятие оптимизации алгоритмов
**Оптимизация алгоритмов** - это процесс улучшения алгоритма для
достижения лучшей производительности по одному или нескольким
ключевым показателям без изменения его конечного результата.

Цель оптимизации алгоритма сделать алгоритм более эффективным с точки зрения использования вычислительных ресурсов.
### Ключевые показатели эффективности
- #### Время выполнения (скорость)
  Уменьшение времени работы алгоритма
- #### Использование памяти
  Снижение объема оперативной памяти, необходимой для работы.
- #### Пропускная способность
  Увеличение количества операций, выполняемых за единицу времени
- #### Энергопотребление
  Снижение энергопотребления

Оптимизация направлена на улучшение одного или нескольких ключевых
показателей эффективности.
## Структурное программирование
**Структурное программирование** - это методология разработки
программного обеспечения, основанная на использовании: линейных
последовательностей, ветвлений (условных операторов), циклов
(итераций). Его применение позволяет создавать более понятные,
поддерживаемые и надежные программы.

Основная идея структурного программирования заключается в разбиении программы на небольшие, логически завершённые блоки(функции, процедуры), что улучшает читаемость,
тестируемость и сопровождение кода.
### Основне принципы структурного программирования
Структурное программирование базируется на нескольких ключевых принципах, направленных на повышение ясности, надежности и удобства
сопровождения кода.
- #### Использование базовых управляющих структур
  Последовательность (выполнение операций строго друг за другом), ветвление (выбор действия на основе условия), циклы(повторение блока кода)

- #### Отказ от неструктурированных переходов
  Запрет на безусловные прыжки, которые усложняют понимание кода.
- #### Модульность и декомпозиция
  Разбиение программы на небольшие, логически завершенные подпрограммы (функции, процедуры), каждая функция должна выполнять одну четкую задачу.
- #### Принцип "один вход – один выход"
  Каждая управляющая структура (функция, цикл, условие) должна иметь единственную точку входа и выхода, это упрощает анализ потока выполнения.
- #### Нисходящее проектирование
  Постепенная детализация (от общей задачи к конкретным подзадачам), сначала проектируется архитектура, затем реализуются отдельные модули.
- #### Читаемость и простота
  Код должен быть интуитивно понятным даже без комментариев, избегание сложных вложенных конструкций.
- #### Предотвращение дублирования кода
  Повторяющиеся фрагменты выносятся в отдельные функции.
## Разновидности структур алгоритмов
Различают три основных разновидности структур алгоритмов.
- **Линейный алгоритм** - это алгоритм, в котором действия выполняются однократно и строго последовательно.
- **Разветвляющийся алгоритм** - это алгоритм, в котором в зависимости от условия выполняется либо одна, либо другая последовательность действий.
- **Циклический алгоритм** - это алгоритм, команды которого повторяются некое количество раз подряд.
### Примеры из жизни
- #### Линейный алгоритм
  Взять зарядное устройство затем подключить кабель к телефону затем вставить вилку в розетку затем дождаться полной зарядки затем отключить зарядное устройство.
- #### Разветвляющийся алгоритм
  Если свет светофора красный, то стоять, иначе переходить дорогу.
- #### Циклический алгоритм
  Пока таймер не достиг двух минут, чистить зубы вверх-вниз.
## Представления алгоритмов
Существуют различные способы представления алгоритмов.
- ### Словесное описание
  Получи два числа $A$ и $B$. Если $A > B$, вывести $A$. Иначе если $A < B$, вывести $B$.
- ### Блок-схема
```text
    Начало
       |
   Ввод A, B
       |
     A > B ?
     /   \
   Да     Нет
   /       \
  v         v
Вывод A   Вывод B
  \         /
   \       /
    v     v
     Конец
```

- ### Псевдокод
```text
алгоритм НайтиМаксимум:
  ввод A, B
  если A > B:
    вывод A
  иначе если A < B:
    вывод B
конец алгоритма
```
- ### Язык программирования
```cpp
#include <iostream>

int main() {
  int a;
  int b;

  std::cin >> a;
  std::cin >> b;

  if (a > b) {
    return a;
  } else if (a < b) {
    return b;
  }

  return 0;
}
```
